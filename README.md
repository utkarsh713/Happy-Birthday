## 💫 About The Project

This is an interactive **Happy Birthday Celebration Website** created to make someone's special day even more memorable. 🎂💖

Instead of a simple birthday message, this website turns the celebration into an interactive experience with animations, surprises, memories, wishes, music, countdowns and celebration effects.

✨ Every section is designed to create a fun and emotional birthday experience.

---

## 🎉 What's Inside?

### 🏠 Home
A beautiful landing page that welcomes the birthday person with an attractive birthday-themed experience.

### 📸 Memories
A dedicated space to showcase beautiful memories, photographs and special moments.

### 💌 Wishes
A collection of heartfelt birthday wishes and messages.

### 🎊 Celebration
The main interactive celebration area with multiple surprises and effects.

### 🎆 Fireworks
Launch beautiful fireworks with a click and make the celebration more exciting.

### 🎊 Confetti Blast
Trigger a colorful confetti celebration whenever you want.

### 🎈 Balloons
Release animated balloons and add more fun to the page.

### 🎁 Floating Gifts
Create a magical gift animation for the birthday celebration.

### ⏳ Countdown
A countdown experience where every second gets closer to the special moment.

### 🎵 Birthday Music
Built-in music player with:

- ▶️ Play / Pause
- 🔊 Volume control
- 📊 Progress bar
- 🎶 Music visualizer
- ⏱️ Playback time
